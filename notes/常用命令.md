# 常用命令

## 0. 编译 buildroot 版本内核

```sh
cd buildroot
make linux-rebuild
```

## 1. 重新编译内核并更新启动文件

### 1.1 在 buildroot 目录下重新编译内核

```sh
cd /home/xuhao/work/100ask/buildroot_100ask_t113-pro/buildroot
make linux-rebuild
```

编译完成后，通常会在 `output/images` 目录下生成这些文件：

- `zImage`
- `sun8iw20p1-t113-100ask-t113-pro.dtb`

### 1.2 重新生成 `boot.img`

注意：

- 修改了内核源码或内核配置后，不能只替换 `zImage`
- 需要使用新的 `zImage` 重新生成 `boot.img`
- 启动分区至少要更新 `boot.img` 和 `dtb`

```sh
cd output/images
touch ramdisk.img
mkbootimg --kernel zImage --ramdisk ramdisk.img --board sun8iw20p1 --base 0x40200000 --kernel_offset 0x0 --ramdisk_offset 0x01000000 -o boot.img
```

### 1.3 推送 `boot.img` 和 `dtb` 到开发板

```sh
mkdir /boot
mount /dev/mmcblk0p4 /boot

adb push boot.img /boot/
adb push sun8iw20p1-t113-100ask-t113-pro.dtb /boot/
adb reboot
```

## 2. 打开内核打印日志

```sh
echo "7 4 1 7" > /proc/sys/kernel/printk
```

## 3. 加载和卸载驱动

```sh
insmod xxx.ko
rmmod dht11_drv
```

## 4. 查看 pinctrl 信息

```sh
cat /sys/kernel/debug/pinctrl/pio/pinconf-pins
```

## 5. 重新配置 buildroot defconfig

```sh
make BR2_EXTERNAL="../br2t113pro ../br2lvgl " 100ask_t113-pro_sdcard_core_defconfig
make V=1
```
