

DS18B20 驱动编写
1. 利用精确延时读取数据
  1.1 读写数据时，关闭中断，完成后恢复
2. 利用平台总线模型



通信协议：
reset： 主机拉低 >= 480us
写bit： 
    0: 拉低 60us
    1： 拉低 1-15us


读数据完成流程：
1. 发送响应信号 reset， 拉低电平
2. 发送命名 skip rom， 0xcc
3. 发送命名 启动温度转换，0x44
4. wait 1s， 等待数据
5.  发送响应信号 reset， 拉低电平
6. 发送命令 skip rom， 0xcc
7. 发送命令读数据  0xbe
8. 读9个字节数据
9. CRC 校验
10. 返回数据到用户空间
